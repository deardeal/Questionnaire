# 資訊圖表色相問卷正式版

共同首頁完成同意與身分選擇，基本資料成功送出後由伺服器以各 25% 機率分派到單、雙、三、四色相之一。每位受測者固定組別，三幅圖順序為法國人的假期、兒童的貧窮率、預防感染。每幅先觀看、隱圖回答三題客觀題，再看圖回答九題主觀題。

## 技術架構

靜態前端 + Netlify Functions + Netlify Database PostgreSQL。GitHub main 更新後由 Netlify 自動部署。題庫來源為 server/survey.mjs，建置時移除答案鍵後輸出 public/data.js。修改題目、選項或圖片時必須提升問卷版本並另行評估既有受測者的版本相容性，不可直接覆蓋正在施測的題庫。

## 網址

- `/`：唯一對外招募入口
- `/hue-1.html`、`/hue-2.html`、`/hue-3.html`、`/hue-4.html`：色相問卷
- `/admin.html`：管理後台

無填答紀錄直接開色相網址會回首頁；有紀錄會回到實際分派組別及目前進度。前端路徑不決定分組，伺服器不接受受測者提供的 hue。此機制限制問卷流程，不能防止截圖、外部筆記或查看已下載的靜態素材。

## 資料與隱私

- 學生：學號、性別、年齡。社會人士：性別、年齡、學歷、職業。
- 收案紀錄包含同意類型、版本、分組、分派時間、完成時間、各頁答案；沒有觀看時間及每題耗時欄位。
- 同一瀏覽器以 HttpOnly Cookie 續填 90 天。跨裝置或清除 Cookie 的社會人士無法可靠判定為同一人；學生另以標準化學號的 HMAC 唯一鍵阻擋第二份填答，不透過學號登入或洩露舊答案。
- 已送出頁面以資料庫交易與資料列鎖保護；重送相同答案視為成功，改寫或跳頁回傳錯誤。
- 研究資料只存在資料庫，不放在 GitHub 或靜態檔案。伺服器日誌不輸出學號、答案或密碼。登入防暴力嘗試保存 IP 的 HMAC 與短期計數，不保存原始 IP；平台本身可能另有基礎服務日誌。

## 後台

淡江學生與社會人士各自顯示四組已分派、已開始題目及完成人數。已開始定義為完成第一幅觀看頁。基本資料未送出另列，不算分派。

CSV 必須指定身分別，提供兩個分開下載。學生 CSV 含學號，社會人士 CSV 不含學號欄。含未完成資料及空白缺漏、不把缺漏算成零分。客觀題以 A–D，主觀題以 1–7 保存。時間以 UTC ISO 8601 匯出，台灣時間為 UTC+8。每個檔案包含色相名稱、數量、問卷／圖片版本、同意版本、圖表順序、分派方法、分派機率與完成狀態。

後台可暫停新填答，既有受測者仍可續填。匯出與開關收案保留管理事件紀錄。沒有永久刪除按鈕。

## 設定與部署

Node 22 以上；`pnpm install --frozen-lockfile`、`pnpm test`、`pnpm build`。

Netlify 設定：build command `npm run build`，publish `public`，functions `netlify/functions`。建立 Netlify Database 後，`netlify/database/migrations` 自動套用資料庫結構。

必填 Functions 環境變數：

- `SESSION_SECRET`：至少 32 字元的高熵祕密。不可任意更換，會影響填答 Cookie 與學號唯一鍵。
- `ADMIN_USERNAME`：正式管理帳號。
- `ADMIN_PASSWORD_HASH`：`scrypt$salt$hex` 格式密碼雜湊；不使用預覽帳密。
- `ENROLLMENT_OPEN`：初始為 `false`，部署驗證後由後台開放。資料庫中的後台設定優先於此初始值。

正式密鑰與初始登入資料存於本機忽略的 `.local/`，不可提交。不要使用公開前端環境變數存放密鑰。Netlify 預覽部署須使用隔離資料庫，不能在正式資料中測試。

## 本機驗證

`pnpm dev` 開啟 http://127.0.0.1:4173 ，使用獨立的 `.local/test-database`。僅限本機測試帳號 `researcher`，密碼 `local-test-only`，不適用正式站。

`pnpm test` 使用記憶體 PostgreSQL 執行分派時點、重試、學號重複、答案鎖定、同時提交、CSV 分離、CSRF、後台登入與限流測試。實際 UI 另驗證三幅圖共 36 題完成、重新整理續填、改網址維持原組，以及後台統計。

## 維運

研究開始前確認同意文字、聯絡方式及樣本納入條件。定期分開下載兩種身分的 CSV，放在研究團隊授權的安全位置；資料庫備份透過 Netlify 備份功能管理。暫停／恢復收案只影響新受測者，不修改原有分派或答案。正式資料累積後，資料清理或刪除需另行確認範圍。
